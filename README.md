# Help Desk TI — Front-end

Aplicação web desenvolvida para a gestão e abertura de chamados de suporte técnico de TI. O sistema permite a autenticação de utilizadores, criação de novos chamados e acompanhamento das solicitações em tempo real.

🌐 **Aceda à Aplicação em Produção:**  
[Help Desk TI — Web App](https://projeto-manu-front-production.up.railway.app/login)

---

## 🛠️ Tecnologias Utilizadas

- **React** (Vite)
- **React Router DOM** (Navegação e Rotas Protegidas)
- **Context API** (Gestão de Estado de Autenticação)
- **React Hook Form + Yup** (Validação de Formulários)
- **Axios** (Consumo da API REST)
- **React Toastify** (Notificações)

---

## 🚀 Funcionalidades

- **Autenticação:** Tela de login com validação de credenciais e persistência de sessão.
- **Abertura de Chamados:** Formulário para criação de chamados com título, descrição e nível de prioridade.
- **Listagem de Chamados:** Visualização dos chamados registados no sistema.
- **Perfil e Permissões:** Identificação de utilizador e perfil de acesso (`role`) no cabeçalho da aplicação.
